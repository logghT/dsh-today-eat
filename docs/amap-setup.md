# 高德「Web 服务」Key 申请与配置（1 分钟）

「附近吃什么」使用高德开放平台的 Web 服务 API（POI 周边搜索、地理编码、天气）。
Key 只保存在你本机的插件状态文件里（`%DSH_HOME%/storages/dsh-today-eat/state.json`），
只会发往 `restapi.amap.com`；不配置 Key 时插件其余功能（推荐/周计划/自制/记录）完全可用。

## 申请步骤

1. 打开 <https://console.amap.com>，注册/登录高德开放平台账号。
2. 完成**个人开发者实名认证**（免费；控制台右上角「账号管理 → 实名认证」）。
3. 进入「应用管理 → 我的应用 → 创建新应用」，名称随意（如 `dsh-today-eat`）。
4. 在该应用下「添加 Key」：
   - **服务平台必须选「Web服务」**（不是「Web端(JS API)」，也不是「iOS/Android」）；
   - 启用服务保持默认（Web 服务 API）；
   - 提交后会得到一串 Key（32 位左右字母数字）。
5. 回到 DSH：打开「今天吃什么」面板 → **设置 → 附近外食** → 粘贴 Key → 保存。
   保存后点「附近吃」即可按你现在的位置（或档案城市）搜索 1.5km 内餐厅。

## 注意事项

- 高德个人开发者有免费日配额；超限时插件会提示 Key 配额/校验错误，第二天恢复或升级配额。
- Key 校验失败时不会崩溃：附近区域显示错误原因，并给出「让 AI 联网搜」兜底。
- 想换/撤销 Key：设置里清空保存即可；建议不要使用公司/他人 Key。
- 插件不会把 Key 写入日志或发送到高德以外的服务；如需更严格隔离，可关闭系统通知/外食搜索，仅用本地推荐。

## 位置说明

- 档案里的城市/区县由用户自行设置，初始为空（不会预置任何地点）。
- 「附近」有 Key 时会先按档案「城市 + 区县」做一次高德地理编码（10 分钟缓存）再搜周边，
  所以出差/换城市只需在设置里改城市与区县，不用手填坐标；地理编码失败时回退档案里内置的经纬度。
- 浏览器可尝试自动定位（需允许定位权限）；桌面端取不到定位时回退档案坐标。
